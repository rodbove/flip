flip

pad sampler · tutorial

Play pads, make a beat, record a sound, chop it and resample it.

Keys are positions, not letters. This page names keys by where they are on a QWERTY keyboard. On other layouts, use the key in the same place. After you press a pad key one time, the pad shows the letter of your layout.

0Start

  1. Run cargo run --release in the flip folder.
  2. To record from the microphone on macOS, run ./scripts/bundle.sh, then open target/Flip.app.
  3. Press / to see the key list in the app.

To install Flip as an app, run ./scripts/install.sh. Flip has no window frame: drag the body to move it, drag the bottom-right ridges to resize it, push HIDE to minimize and OFF to quit.

  • Group A has drums. Group B has synth notes. Use ← → to change the group.

1+Pick a mood

  1. Press = or click the MOOD tab.
  2. Click a mood, for example SAMBA or TRAP. It loads drums into group A, bass into B, keys into C and leads with effects into D.
  3. Click BEAT to write the demo beat and bass line of the mood. This also sets the tempo and swing.
  4. Select a pad and click DICE (or press L) to get a new sound in the same mood. Cmd Z undoes it.

The KEYS screen (-) shows the keys you play in orange and the recorded notes that play back in blue. It opens by itself when a MIDI keyboard sends notes.

2Make a beat

  1. Press Space to play. Pattern A01 already has a beat.
  2. Press 6 to show the step grid.
  3. Click a cell to set or remove a step.
  4. Right-click a step that is on. The STEP page opens. Use the knobs to set the velocity, the note and the chance.

Live recording: press Enter while the pattern plays, then hit pads. Each hit goes to the nearest step.

3Shape a sound

  1. Select a pad. Hit it, or Shift-click it, or right-click it.
  2. Select a page: TRIM ENV FILTER SYNTH PLAY MIX.
  3. Drag a knob up or down. Hold Shift for small changes.
  4. Double-click a knob to reset it.

4Record a sound

  1. Select an empty pad. Groups C and D are empty.
  2. Open the REC page. Set SOURCE (INPUT, MASTER or a group) and THRESH.
  3. Press B or click SAMPLE. Recording starts when the sound is louder than THRESH.
  4. Press B again to stop.

You can also drop audio files on the window. Each file goes into a pad, starting at the selected pad.

5Chop a sample

  1. Select a pad with a long sample, for example a drum loop.
  2. Click CHOP. Flip cuts the sample at each hit and puts one slice on each pad, starting at pad 01.
  3. Drag the S and E markers on the screen to adjust a slice.

6Resample

  • BOUNCE renders the current pattern onto a free pad.
  • For a live take, set SOURCE to MASTER, press B, then play.
  • Chop the new sample, play it again, then bounce again. This is the main loop of the instrument.

7Patterns and song

  • Each group has 16 patterns, on the keys below the pads. [ and ] also select patterns.
  • Right-click a pattern key to copy the current pattern into it.
  • On the STEP page, LENGTH sets 16, 32, 48 or 64 steps.

To make a song:

  1. Press 7 to show the song screen.
  2. Select a pattern in each group.
  3. Click + ADD. Do this again for each part.
  4. Click SONG ON.

8Save and export

Cmd SSave the project folder. The default place is ~/Music/Flip.
Cmd EExport a WAV file of the pattern. In song mode, export the song.
Cmd ZUndo.
Cmd OOpen a project folder.

9MIDI

  • Click SETUP to select the MIDI port and the audio devices.
  • Notes 36 to 51 play the pads. Note 36 is the bottom-left pad.
  • Other notes play the selected pad at that pitch.
  • To map a knob: right-click the knob, then turn a control on your controller.

10Play a keyboard

  1. Connect the keyboard to the computer with a USB cable. On a Yamaha PSR-E333, use the USB TO HOST port.
  2. Click SETUP and select the keyboard as the MIDI port.
  3. Select a pad. Push P to open the presets. Use the arrows to find a sound, then push Enter.
  4. Push , or . to try the previous or next preset without the list.
  5. Push Tab for keys mode. Now all keys play the selected pad, also the low keys.
  6. Push Space to play, then Enter to record. Play chords and hold notes. The sustain pedal also works.
  7. Push 8 to see the notes in the roll. Click to add a note, drag to move it, drag the right edge to change the length, right-click to delete it.
  8. Push 9 to change the record grid. Push 0 to snap the notes of the pad to the grid.
  9. To keep a sound, push Shift + P and type a name.

The SYNTH page changes with the engine. Set the engine on the REC page: ANALOG, FM, STRING or MORPH. On FM, click the page again to edit operators 1 to 4.
